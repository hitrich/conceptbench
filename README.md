# ConceptBench

An open-source workspace for deciding what to improve, which audience to focus on, and what to test next.

ConceptBench connects behavioral aggregates, human feedback, and experimental concept testing in a traceable Decision Brief. Its synthetic demo illustrates an acquisition-mix change that looks like a product retention problem until you inspect the evidence.

## Building in public

This repository is being developed in working vertical slices. The initial target is a self-hosted pilot: React + TypeScript, Django + Django Ninja, PostgreSQL, and one durable background worker. The local development path also supports SQLite.

- [Build scope and acceptance gates](docs/BUILD.md)
- [MIT license](LICENSE)

All bundled examples are fabricated. They do not establish product-market fit, validate pivot forecasting, or demonstrate the reliability of synthetic respondents for SaaS decisions.
